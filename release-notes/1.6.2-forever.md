## [1.6.2-forever] - 2026-11-21

### WoW Forever (1.60.1 / Interface 16001) Port

Based on [CrosshairsPlus v1.6.2](https://github.com/mikhaben/CrosshairsPlus) by **justLuther** (MIT License).

**Changed**
- Targeted WoW Forever client interface (`16001`) in both `CrosshairsPlus.toc` and `CrosshairsPlus_Range.toc`.
- Updated embedded `LibRangeCheck-3.0` to revision 39 (adds `isForever` detection, `issecretvalue` GUID cache guard, and safe `LEARNED_SPELL_IN_TAB` registration).
- Updated installation docs and removed upstream Retail CurseForge/Wago project IDs for the standalone Forever port.

**Fixed**
- Added secret-value guards across `UnitLogic.lua`, `TargetInfo.lua`, `Attach.lua`, `Debug.lua`, and `Init.lua` so combat/instance restricted unit values never raise Lua errors.
- Guarded `PLAYER_SOFT_ENEMY_CHANGED` registration with `C_EventUtils.IsEventValid`.
- Avoided false nameplate CVar warnings when a CVar is absent (`nil`).
